Frequently asked questions

Chapter 14 of 14 · Updated 18 Nov 2026

This page gathers the most common questions about using ATPBR. If your question is not here, contact the ATPBR team by e-mail at atpbr@inca.gov.br.

About ATPBR#

Does ATPBR receive data that identifies patients?

Not directly. ATPBR only receives data that has been de-identified beforehand by the participating institutions: names, identity documents, medical record numbers, contact details and dates of clinical events must not be sent, and the link between the codes and the individuals is kept only at the institution of origin. Even so, the data is pseudonymized, not anonymized, and is therefore protected as sensitive personal data. Learn more in Data governance and Usage policies.

Which types of omics data are accepted?

WGS, WES, gene panel and RNA-seq. Other modalities, such as DNA methylation, will be added in future versions. See Data types.

Registration and submission#

In what order should I register the information?

Project → Investigation → Study → Patients → Samples → Assay → Data Files → Experiments. Each step depends on the previous one. The step-by-step guide is in Data submission, and the reason for this order is in Data model.

Can I register several patients, samples or experiments at once?

Yes, using the template spreadsheets (Excel, .xlsx or .xls), which you can download from the registration page itself. See Data types.

My collector center does not appear in the list on the patient registration form. What should I do?

The collector center must be among the Project's Associated Institutions. Edit the Project and add the institution; from then on, it appears in the "Collector Center" list on the patient registration form. See Identification and barcode system.

Why can't I create a second Study with the same cancer type?

Within a single project, each cancer type can have only one Study. New patients with that cancer type must be registered in the existing Study.

Why doesn't the cancer type I am looking for appear on the patient registration form?

The patient's cancer type options are limited to the tissue defined in the Study. If the type you are looking for belongs to another tissue, it must be registered in the corresponding Study.

Dates and time#

Why can't I enter dates, such as the date of diagnosis or collection?

Combined with one another, the dates of clinical events make it possible to re-identify the patient. That is why temporal fields take the number of days counted from the diagnosis. See Data dictionary.

What is "day 0"?

It is the date of diagnosis, that is, of the first exam that concluded malignancy. All other events are counted from it. For example, a sample collected 15 days after diagnosis must be entered with the value 15 in days_to_sample.

How do I convert the dates in the medical record into a number of days?

Use the date-to-days converter, available in the platform's registration forms. The conversion is done on your own computer, and the original dates must not be sent to ATPBR.

Is there any date that must be entered as a date?

Yes, only the sequencing date (date_of_sequencing), in DD/MM/YYYY format, because it does not refer to the patient.

Identifiers and barcode#

Who defines the patient_id and the sample_id?

The collector center. Both are 4-digit codes and must be unrelated to personal data: for example, do not use the medical record number or parts of the date of birth.

Do I need to fill in the barcode?

No. The barcode is generated automatically by the platform from the fields entered when registering the patient, the sample and the experiment. See Identification and barcode system.

Why does "XXX" appear in the barcode?

"XXX" indicates that one of the fields used to compose the barcode has not been filled in yet or could not be identified. Check the record's required fields.

Why does the run number appear as "00"?

The run number is assigned from the combination of sequencing date, sequencing center and sequencing platform. As long as any of these three fields is not filled in, the run appears as 00.

I received a duplicate registration warning. What does it mean?

The platform does not accept two records with the same barcode. The warning indicates that a patient, sample or experiment with the same identification data already exists. Check whether the record was registered earlier or whether the code you entered is correct.

Samples#

My sample was rejected for missing staging. Why?

Every sample must provide at least one staging system (FIGO, TNM, Rai, Binet, LMC Phase, AML/ALL Stage or CIN). The system that applies to the case is enough; the AJCC fields do not meet this requirement. See Data dictionary.

Where do I enter the collection tube anticoagulant (EDTA, citrate)?

In the collection_tube_additive field (collection tube additive), which is optional. This field is not part of sample preservation and is not included in the barcode.

Sequencing files#

In what format should I submit the sequencing files?

Gzip-compressed FASTQ (.fastq.gz or .fq.gz). For paired-end reads, submit both files for each sample. See Data types.

Why can't I register the experiments before submitting the FASTQ files?

Each experiment indicates, in the fastq_1 and fastq_2 fields, which files belong to that sample. That is why the files must be available in the Assay before the experiments are registered. See Data submission.

My FASTQ files are already on the INCA Multi-user Bioinformatics Platform. Do I need to submit them again?

No. Enter the absolute path of the directory where the files are stored in the Assay's Associated Repositories field. See Data submission.

I received a warning that a FASTQ file was not found. What does it mean?

The name entered in fastq_1 or fastq_2 does not match any file in the Assay. Check that the file was submitted to the correct Assay and that the name was typed exactly the same, including the extension.

Can the FASTQ file name contain the patient's name or the medical record number?

No. File names must not contain personal data either. Rename the files before submitting them, if necessary.

Do I need to submit BAM, CRAM or VCF files?

No. These files are generated by the ATPBR pipelines from the submitted FASTQ files. See Analysis platform.

Do I need to run any pipeline?

No. The pipelines are run centrally by the ATPBR team. See Analysis platform.

Governance and ethics#

What is the Submitting Researcher's Responsibility Agreement?

It is the agreement the researcher accepts before submitting data to ATPBR. In it, the researcher declares that the data is authentic and has been de-identified, that they will provide the ethics documentation and the use permissions of each dataset, and that they will report changes, such as consent withdrawals or new restrictions. See Data submission.

My study has ethics approval. Is that enough to share the data in ATPBR?

Not necessarily. The ethics approval of the original study does not, by itself, authorize new uses or sharing. You must check whether the informed consent form (TCLE) and the protocol allow inclusion in ATPBR and future use of the data, and whether the institution of origin authorizes the sharing. See Data governance.

The system accepted my data. Is it already available to other researchers?

No. Being accepted by the system is not the same as being admitted. Each dataset goes through technical and ethical-documentary checks and only becomes available after it is recorded as eligible. Pending datasets remain blocked until the issues are resolved. See Data submission.

I filled in the ethics approval field. Do I need to send any document?

Yes. The completed field does not replace the supporting document. The ATPBR team may request the approval opinion of the Research Ethics Committee (CEP) or of the National Research Ethics Commission (Conep), the version of the TCLE (or the consent waiver decision) and the data transfer agreement. See Data governance.

A participant has withdrawn consent. What should I do?

Notify the ATPBR team by e-mail at atpbr@inca.gov.br, identifying the participant only by the code used on the platform (patient_id or barcode), never by name or identity document. ATPBR blocks new uses of the data and, when necessary, notifies the researchers who have already received it. See Data governance.

Does data access include the biological samples?

No. Access to data and access to or transfer of samples are separate authorizations. Decisions about samples rest with the institutions that hold them. See Data governance.

Data access#

Which data can I consult without requesting authorization?

The information approved for public release: the metadata in the Data catalog and the results published in the Results browser (ATPBR cBioPortal).

Who decides whether my project's data appears in cBioPortal?

The person responsible for the project indicates, when registering each Assay, whether the data can be made available. Publication, however, only happens after the dataset is validated and the release is approved, with an assessment of re-identification risks and in compliance with the participants' consent and the original permissions. FASTQ and CRAM files always remain under controlled access. See Data access.

How do I obtain access to controlled-access data, such as FASTQ, CRAM or germline variants?

Submit an access request in the access request module of the ATPBR platform, using your institutional login (questions: atpbr@inca.gov.br). The access request is reviewed by the Data Access Committee (CAD) and, if approved, release depends on signing the data use agreement. CAD authorization does not replace the ethics approval of your research. See Data access.

Can my collaborators use my access?

No. Access is individual and accounts cannot be shared. Each collaborator must be identified in the access request and accept the same obligations. See Usage policies.

How should I cite ATPBR?

Cite ATPBR and the studies from which the data originates. The reference article is in About ATPBR, and the usage rules are in Usage policies.
