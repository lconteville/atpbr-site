Welcome to ATPBR!#

This section was created to help new users quickly understand the structure of the platform and find the resources they need for their activities. Whatever your profile, we recommend reading this page before exploring the other areas of the documentation.

How the documentation is organized#

The chapters follow the data life cycle in ATPBR, from submission to the exploration of results. Each chapter builds on the previous one and points, at the end, to the next step:

  1. About ATPBR: the project's objectives, mission and principles.
  2. Start here: this page.
  3. Platform architecture: an overview of the path that data take.
  4. Data governance: who is responsible for each stage, how participants are protected and which authorizations each use requires.
  5. Data submission: the step-by-step guide to registering a project and sending your data.
  6. Data access: what is open, what is controlled and how to request access.
  7. Data model: how the registered information is organized and interrelated.
  8. Data dictionary: the fields of each module and the rules for filling them in.
  9. Identification and barcode system: how the platform identifies patients, samples and assays.
  10. Data types: the formats accepted for submission and the files generated by the platform.
  11. Analysis platform: how submitted data are processed.
  12. Results browser: how to explore the results in the ATPBR cBioPortal.
  13. Usage policies: the responsibilities of those who use the data.
  14. Frequently asked questions: quick answers to the most common questions.

Choose your profile#

If you do not intend to read the documentation in order, start with the path closest to your needs:

  • I want to submit data#

Read Data governance, which explains the responsibilities of those who submit data and the ethics documentation required. Then continue from Data submission through Data types. These chapters cover everything you need for registration.

  • I want to explore results#

Start with the Results browser. To understand how these results were generated, see the Analysis platform.

  • I want to access controlled-access data#

Read Data governance, Data access and Usage policies.

Need help?#

See the Frequently asked questions section.
If you need further support, contact the ATPBR team by email at atpbr@inca.gov.br.
