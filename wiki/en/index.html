ATPBR Documentation

Version 0.1 · ATPBR platform user documentation · in English

The Brazilian Population Tumor Atlas (ATPBR) is a national initiative that maps the molecular profile of cancer in Brazilians and shares these data responsibly. This wiki gathers the user documentation of the platform: how to submit data, how the data are organized, identified and processed, and how to access them.

New here? Start with the Start here page, which suggests a reading path for each profile.
